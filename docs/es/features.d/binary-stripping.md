# Stripping de binarios con informe de tamaño (b19-strip)

- Cualquier binario puede someterse a stripping in situ, midiendo automáticamente el tamaño antes y después y registrando la reducción porcentual.
- Reduce el tamaño de la imagen final al eliminar símbolos de depuración y metadatos innecesarios de los binarios compilados.
