# Статичні збірки з типово вимкненим CGO

- `CGO_ENABLED=0` — типове значення, яке дає статично злінковані бінарники без залежності від libc.
- Бінарники, зібрані в цьому образі, працюють на будь-якій Linux-системі незалежно від встановленої C-бібліотеки.
