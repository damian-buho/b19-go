# Stripping бінарних файлів зі звітом про розмір (b19-strip)

- Будь-який бінарний файл можна очистити на місці з автоматичним вимірюванням розміру до і після та записом відсотка зменшення в журнал.
- Зменшує розмір підсумкового образу, видаляючи символи налагодження та непотрібні метадані зі зібраних бінарних файлів.
